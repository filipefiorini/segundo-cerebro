# _assets

Pasta para armazenar imagens e arquivos locais do vault.

## Convenção de uso

- Banners de templates: `banner-nome-do-template.png`
- Imagens de notas: `nome-descritivo.png` ou `nome-descritivo.jpg`
- Outros anexos: nomeados de forma descritiva, sem espaços

## Como referenciar nas notas

```
![[_assets/nome-do-arquivo.png]]
```
