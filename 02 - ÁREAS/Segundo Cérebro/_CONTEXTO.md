# 🗺️ Segundo Cérebro

## 📌 Descrição
A área que administra o próprio vault: estrutura de pastas, regras do `CLAUDE.md`, templates, skills, taxonomia e a memória do Code. Não guarda conhecimento sobre outros assuntos; guarda as decisões sobre como o sistema funciona.

## 📊 Estado Atual
Vault recém-instalado a partir do framework. A Galáxia e as Fontes podem trazer notas de exemplo (`exemplo: true`), opcionais: o `/instalar` pergunta se você as quer e, a pedido, as remove.

## 🎯 Objetivos
Manter o vault fácil de usar e confiável: notas no lugar certo, links íntegros, regras que o Code segue sem ambiguidade.

## 📅 Rituais e Rotinas
