# 💡 Organize pelo que vai fazer, não pelo assunto

## 🧬 Ideia Central
> A organização por assunto é intuitiva mas inútil na prática — porque não diz o que fazer com a informação. A pergunta certa ao arquivar qualquer coisa é: "Em qual projeto ou área isso vai servir?"

## 📖 Desenvolvimento
Pastas organizadas por assunto ("Saúde", "Marketing", "Filosofia") viram cemitérios de informação. Você sabe onde está o arquivo, mas nunca o abre porque não sabe o que fazer com ele.

O sistema PARA resolve isso dividindo tudo pelo que você vai FAZER com a informação: **Projetos** (resultados com prazo), **Áreas** (responsabilidades contínuas), **Recursos** (referência para uso futuro) e **Arquivo** (o que não está mais ativo). O IPARAG deste vault é uma extensão desse princípio.

Exemplo: uma nota sobre "técnicas de persuasão" não vai para uma pasta "Psicologia". Vai para o projeto de vendas em que você está trabalhando — porque é ali que ela vai ser usada.
