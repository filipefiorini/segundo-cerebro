# 💡 O cérebro é para ter ideias, não para guardá-las

## 🧬 Ideia Central
> O cérebro humano é otimizado para gerar e conectar ideias — não para armazená-las. Um sistema externo e confiável libera o cérebro para o que ele faz melhor: pensar.

## 📖 Desenvolvimento
Toda vez que usamos a memória como depósito de informação, estamos desperdiçando capacidade cognitiva. O resultado é o sentimento constante de "já li isso em algum lugar" ou "tive essa ideia antes mas esqueci" — a memória é volátil e seletiva, não é um arquivo confiável.

Criar um Segundo Cérebro libera a mente para pensamento criativo e tomada de decisão. É o "GTD para o conhecimento" — assim como David Allen propõe esvaziar a mente de tarefas, Forte propõe esvaziar a mente de informação.

## 💼 Aplicação Prática
Toda vez que tentar memorizar algo que poderia estar no vault, é sinal de uso inadequado do sistema. A regra é: se vale guardar, guarda no vault — não na cabeça.
