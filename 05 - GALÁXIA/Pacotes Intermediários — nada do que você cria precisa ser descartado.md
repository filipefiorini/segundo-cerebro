# 💡 Pacotes Intermediários — nada do que você cria precisa ser descartado

## 🧬 Ideia Central
> Em vez de trabalhar em projetos do zero ao fim de forma linear, acumule pacotes intermediários — fragmentos de trabalho com valor independente que podem ser remontados em qualquer projeto futuro.

## 📖 Desenvolvimento
Um pacote intermediário é qualquer unidade de trabalho que pode existir de forma independente: um parágrafo bem escrito, uma lista de argumentos, um diagrama, um resumo. São blocos de construção reutilizáveis.

Projetos novos começam com material já existente, não do zero. O trabalho acumula valor composto ao longo do tempo. Reduz o "bloqueio criativo" — sempre há algo para começar.

**Processo:**
1. Ao criar qualquer conteúdo, salve os fragmentos que têm valor independente
2. Arquive-os no projeto ou área correspondente
3. Ao iniciar um novo projeto, pesquise o vault antes de começar do zero

**Exemplo:** Um resumo feito para um projeto de vendas pode virar o núcleo de um post, que vira parte de uma newsletter, que vira um capítulo de um e-book. O mesmo bloco, remontado de formas diferentes.

Antes de criar qualquer conteúdo novo: buscar no vault o que já foi produzido sobre o tema. Cada análise, resumo ou relatório já feito para o trabalho é um pacote intermediário reutilizável.
