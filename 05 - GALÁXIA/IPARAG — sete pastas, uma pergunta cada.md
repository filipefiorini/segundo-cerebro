# 💡 IPARAG: sete pastas, uma pergunta cada

## 🧬 Ideia Central
> O IPARAG organiza o vault em sete pastas, e cada uma responde a uma pergunta sobre o uso que o arquivo terá, nunca sobre o assunto dele.

## 📖 Desenvolvimento
| Pasta | Pergunta |
|---|---|
| `00 - INBOX` | Preciso guardar isso agora? |
| `01 - PROJETOS` | Tem entregável definido? |
| `02 - ÁREAS` | É algo que mantenho sempre? |
| `03 - RECURSOS` | Vou reusar em vários contextos? |
| `04 - ARQUIVO` | Acabou ou perdeu validade? |
| `05 - GALÁXIA` | É um insight atemporal meu? |
| `06 - TAREFAS` | É algo a fazer? |

Nenhum arquivo mora em duas pastas. Na dúvida, o agente pergunta antes de gravar.

## 🔗 Conexões
- Apoia: [[Da captura à Galáxia — o caminho de uma nota]]
- Relacionado com: [[Mapa de Responsabilidade — cada arquivo tem dono e escopo]]
- Apoia: [[Organize pelo que vai fazer, não pelo assunto]]

## 💼 Aplicação Prática
Tudo entra pelo INBOX. Para dar destino a uma nota, faça as perguntas das outras pastas, de cima para baixo, e pare na primeira que for sim; se nenhuma for, ela espera no INBOX.

## 📎 Fonte
Experiência de desenhar e operar este vault. A estrutura de pastas vem do LIFE OS Vault (Noah's Ark Bank), que parte do PARA de Tiago Forte; a pasta de tarefas é deste projeto.
