# 💡 O método CODE — Capturar, Organizar, Destilar, Expressar

## 🧬 Ideia Central
> CODE é o fluxo completo de um Segundo Cérebro: quatro etapas que fecham o ciclo entre consumo e criação. O sistema só tem valor quando gera Expressão.

## 📖 Desenvolvimento
Cada etapa tem uma lógica própria e um erro típico de quem a pula:

1. **Capturar** — salvar apenas o que ressoa, não tudo que consome. Erro: salvar tudo ou não salvar nada.
2. **Organizar** — arquivar por projeto ou área de utilidade futura, não por assunto. Erro: organizar por tema sem pensar no uso.
3. **Destilar** — comprimir a informação camada por camada até sua essência. Erro: nunca reler ou sintetizar.
4. **Expressar** — usar o que foi acumulado para criar, não só consumir. Erro: acumular infinitamente sem gerar output.

CODE não é linear — você pode entrar em qualquer etapa. Mas sem a etapa final (Expressar), o sistema é um arquivo morto. A maioria das pessoas só faz a primeira etapa (captura) e nunca chega na última.
