# 💡 Toda tarefa nasce com prazo

## 🧬 Ideia Central
> Quando uma tarefa surge sem data, ela recebe o prazo padrão do dia útil seguinte e uma marca para você rever a data depois.

## 📖 Desenvolvimento
A regra FONTE-DE-TAREFAS do `CLAUDE.md` diz que toda tarefa vive em `06 - TAREFAS/Tarefas/`, uma nota por tarefa, com `projects`, `executor` e `due`. Nenhuma nasce sem `due`.

Se a fonte (uma ata, uma captura) não traz prazo, o Code grava `due` no dia útil seguinte e acrescenta `prazo_padrao: true`. O Painel de tarefas destaca essas tarefas. Quando você muda a data, o painel apaga a marca.

Assim nada fica sem data e a data inventada não passa por combinada.

## 💼 Aplicação Prática
Na revisão semanal, filtre as tarefas com `prazo_padrao: true` e confirme ou troque cada data. Quem aceita a data padrão sem ler está só adiando o problema.
