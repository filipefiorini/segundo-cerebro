# Código de conduta

Este projeto é pequeno e aberto. Para manter assim:

- Trate as pessoas com respeito, mesmo ao discordar.
- Critique a ideia, o código ou o texto, nunca a pessoa.
- Não publique dado pessoal de terceiros: nome, telefone, endereço, documento, conteúdo de conversa. Isto vale para issues, PRs e comentários.
- Não publique dado pessoal seu nem conteúdo das suas notas. As páginas do repositório são públicas.

Quem não seguir isso pode ter comentário, issue ou PR removido e ser bloqueado do repositório.

## Como relatar

Abra uma issue descrevendo o que aconteceu, sem repetir o dado pessoal em questão. Não há e-mail de contato. Falha de segurança tem caminho próprio, descrito em [SECURITY.md](SECURITY.md).
